# Translations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Translate every user-facing string in the extension, with French as the first and only shipped catalog.

**Architecture:** A pure `lib/i18n.js` holds a translator that defaults to identity, so `lib/` stays importable by `node --test` while `extension.js` installs the shell's real gettext at `enable()`. Module-level string constants keep English msgids and are translated where they are read, never where they are declared. Catalogs are standard gettext — `po/` for translators, a committed `locale/**.mo` because this checkout is what a user installs.

**Tech Stack:** GJS / GNOME Shell 50, `node --test`, GNU gettext (`xgettext`, `msgmerge`, `msgfmt`), `Intl.NumberFormat`.

**Spec:** [`docs/superpowers/specs/2026-08-13-i18n-design.md`](../specs/2026-08-13-i18n-design.md)

## Global Constraints

- **No WHAT comments.** Only a hidden constraint or a surprising reason earns a comment. The existing files show the bar.
- **`lib/` must not import `gi://`** — every module except `lib/usage.js` is imported by `node --test`. `lib/i18n.js` and `lib/errors.js` are pure.
- **No blank lines inside a function body.** Extract instead.
- **Tests travel with code.** Every task ends green on `npm test` and `npm run lint`.
- **Never touch the host GNOME session.** Every dconf write stays inside `tools/lib/devkit.sh`'s `dbus-run-session`. After any task that starts a shell, confirm: `sha256sum ~/.config/dconf/user` and the length of `gsettings get org.gnome.shell enabled-extensions` unchanged.
- **A nested session spends no requests.** `wc -l ~/.cache/claude-quota/attempts.jsonl` must not move across any task.
- **Commits are signed** (`git commit -S`) and carry no `Co-Authored-By` trailer. If gpg cannot sign from the agent shell, stage and hand the `git commit -S -F <file>` line to the user.
- **gettext domain:** `claude-quota`. **Locale for the tryout:** `fr_FR.UTF-8` (confirmed generated on this host).
- **`origin` is unreachable until 2026-08-15** — commit locally, do not push.

- [ ] **Step 2: Write the regeneration script**

Create `tools/i18n.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
DOMAIN=claude-quota
POT="$ROOT/po/$DOMAIN.pot"
LANGS=(fr)

KEYWORDS=(--keyword=_ --keyword=N_ --keyword=n_:1,2 --keyword=p_:1c,2 --keyword=describe:1)

extract() {
    local out="$1"
    (cd "$ROOT" && xgettext --language=JavaScript --from-code=UTF-8 \
        "${KEYWORDS[@]}" \
        --package-name="$DOMAIN" \
        --copyright-holder='e7d' \
        --msgid-bugs-address='michael@e7d.io' \
        --output="$out" \
        extension.js lib/*.js)
}

merge() {
    local pot="$1" lang
    for lang in "${LANGS[@]}"; do
        msgmerge --quiet --update --backup=none "$ROOT/po/$lang.po" "$pot"
    done
}

compile() {
    local lang dir
    for lang in "${LANGS[@]}"; do
        dir="$ROOT/locale/$lang/LC_MESSAGES"
        mkdir -p "$dir"
        msgfmt --check --output-file="$dir/$DOMAIN.mo" "$ROOT/po/$lang.po"
    done
}

# A msgid added in code and never extracted falls back to English silently, which is
# indistinguishable from a translation nobody wrote yet.
check() {
    local tmp lang status=0
    tmp="$(mktemp -d)"
    trap 'rm -rf "$tmp"' RETURN
    extract "$tmp/$DOMAIN.pot"
    if ! diff -q <(grep -v '^"POT-Creation-Date' "$POT") \
                 <(grep -v '^"POT-Creation-Date' "$tmp/$DOMAIN.pot") >/dev/null; then
        echo "po/$DOMAIN.pot is stale — run npm run i18n" >&2
        status=1
    fi
    for lang in "${LANGS[@]}"; do
        msgfmt --check --output-file="$tmp/$lang.mo" "$ROOT/po/$lang.po"
        cmp -s "$tmp/$lang.mo" "$ROOT/locale/$lang/LC_MESSAGES/$DOMAIN.mo" || {
            echo "locale/$lang/LC_MESSAGES/$DOMAIN.mo is stale — run npm run i18n" >&2
            status=1
        }
    done
    return "$status"
}

case "${1:---all}" in
    --check) check ;;
    --all) extract "$POT"; merge "$POT"; compile ;;
    *) echo "usage: i18n.sh [--all|--check]" >&2; exit 2 ;;
esac
```

Then `chmod +x tools/i18n.sh`, and add to `package.json`:


- [ ] **Step 3: Write the module**

Create `lib/i18n.js`:

```js
let translator = null;

export function setTranslator({gettext, ngettext, pgettext}) {
    translator = {gettext, ngettext, pgettext};
}

export function resetTranslator() {
    translator = null;
}

export function _(msgid) {
    return translator ? translator.gettext(msgid) : msgid;
}

export function n_(msgid, plural, count) {
    if (translator)
        return translator.ngettext(msgid, plural, count);
    return count === 1 ? msgid : plural;
}

export function p_(context, msgid) {
    return translator ? translator.pgettext(context, msgid) : msgid;
}

export function N_(msgid) {
    return msgid;
}

export function format(pattern, values = {}) {
    return pattern.replace(/\{(\w+)\}/g, (placeholder, name) =>
        Object.hasOwn(values, name) ? String(values[name]) : placeholder);
}
```

```js
import {N_, _, p_} from './i18n.js';

const NAMES = {session: N_('Session (5h)'), weekly_all: N_('Weekly')};
const SHORTS = {session: ['panel initial', 'S'], weekly_all: ['panel initial', 'W']};

function quotaName(limit) {
    if (NAMES[limit.kind])
        return _(NAMES[limit.kind]);
    return limit.scope?.model?.display_name || limit.kind;
}

function assignShort(kind, name, used) {
    if (SHORTS[kind]) {
        const short = p_(...SHORTS[kind]);
        used.add(short);
        return short;
    }
    let label = name.slice(0, 1).toUpperCase();
    let next = 1;
    while (used.has(label) && next < name.length) {
        label += name[next].toLowerCase();
        next += 1;
    }
    let suffix = 2;
    while (used.has(label)) {
        label = label + suffix;
        suffix += 1;
    }
    used.add(label);
    return label;
}
```

### Task 5: Translate the formatted lines

The largest task, and the one carrying the design's real finding: `left` cannot be a msgid of its own, because French agrees the participle with whichever unit leads the duration.

**Files:**
- Modify: `lib/format.js` (whole file)
- Modify: `extension.js:19` (import), `extension.js:137`, and the `percentLine` call sites
- Test: `test/format.test.js`

**Interfaces:**
- Consumes: `_`, `n_`, `format` from `lib/i18n.js`
- Produces:
  - `remainingLine(target: Date, now: Date)` → `string` — replaces `relativeDuration`, and now includes the trailing "left"
  - `numberLocale(env: object)` → `string | undefined` — new, mirrors `timeLocale` but reads `LC_NUMERIC`
  - `percentLine(quota, locale?)` → `string` — gains a second parameter
  - `captionLine`, `refreshLine`, `rateLimitLine`, `serviceUntilLine`, `rateLimitMessage` keep their signatures
  - on the indicator: a new `_percentLocale` field, and `QuotaBlock.update` gains a `percentLocale` key

**Deviation from the spec, deliberate:** the spec had the percent use the same locale as the clock. It gets its own `numberLocale()` reading `LC_NUMERIC` instead, because that is the variable that governs it — and this host is a live example, running `LANG=en_US.UTF-8` with `LC_NUMERIC=fr_FR.UTF-8`.

```js
import {_, format, n_} from './i18n.js';

function posixLocale(posix) {
    const tag = posix.split('.')[0].split('@')[0].replace('_', '-');
    if (tag === '' || tag === 'C' || tag === 'POSIX')
        return undefined;
    return tag;
}

export function timeLocale(env) {
    return posixLocale(env.LC_ALL || env.LC_TIME || env.LANG || '');
}

export function numberLocale(env) {
    return posixLocale(env.LC_ALL || env.LC_NUMERIC || env.LANG || '');
}

export function remainingLine(target, now) {
    const remaining = target - now;
    if (remaining <= 0)
        return _('now');
    if (remaining >= DAY)
        return daysLeft(remaining);
    if (remaining >= HOUR)
        return hoursLeft(remaining);
    const minutes = Math.max(1, Math.floor(remaining / MINUTE));
    return format(n_('{m}m left', '{m}m left', minutes), {m: minutes});
}

function daysLeft(remaining) {
    const days = Math.floor(remaining / DAY);
    return format(n_('{d}d {h}h left', '{d}d {h}h left', days),
        {d: days, h: Math.floor((remaining % DAY) / HOUR)});
}

function hoursLeft(remaining) {
    const hours = Math.floor(remaining / HOUR);
    const minutes = Math.floor((remaining % HOUR) / MINUTE);
    return format(n_('{h}h {m}m left', '{h}h {m}m left', hours),
        {h: hours, m: String(minutes).padStart(2, '0')});
}

export function percentLine(quota, locale = undefined) {
    if (quota.expired || !Number.isFinite(quota.percent))
        return '-';
    return new Intl.NumberFormat(locale, {style: 'percent', maximumFractionDigits: 0})
        .format(quota.percent / 100);
}

export function captionLine(quota, now, locale = undefined) {
    if (quota.expired || !quota.resetsAt)
        return '-';
    return format('{remaining} · {time}', {
        remaining: remainingLine(quota.resetsAt, now),
        time: absoluteTime(roundToMinute(quota.resetsAt), now, locale),
    });
}

export function refreshLine(fetchedAt, now, locale = undefined) {
    const time = fetchedAt === null ? '-' : absoluteTime(fetchedAt, now, locale);
    return format(_('Last refresh: {time}'), {time});
}

export function rateLimitLine(until, now, locale = undefined) {
    if (!until)
        return '';
    const target = roundToMinute(until);
    const time = absoluteTime(target, now, locale);
    return isSameDay(target, now)
        ? format(_('retry at {time}'), {time})
        : format(_('retry {time}'), {time});
}

export function serviceUntilLine(until, now, locale = undefined) {
    if (!until || until <= now)
        return '';
    return format(_('until {time}'), {time: absoluteTime(roundToMinute(until), now, locale)});
}

export function rateLimitMessage(until, now, locale = undefined) {
    const line = rateLimitLine(until, now, locale);
    return line === '' ? '' : `⏳ ${_('Rate limited')} · ${line}`;
}
```
